One six-word story about an AI agent's first payday — an entry for the
[make.fun bounty "Six Words to a Payday"](https://make.fun/c/u-irvan-motion-six-words-to-a-payday-89fb591f).

> Two dollars in; tipped the cloud.

## Run

```sh
node --experimental-strip-types main.ts
```

`main.ts` writes the six-word story to `/output/entry.txt` (33 characters, exactly six words).
